# AI VOICE ASSISSTANT
About the Project

This is a simple yet practical voice assistant built using Python. The idea behind this project was to create something that can actually talk and listen, not just process text like most basic AI demos.

You speak into your microphone, the assistant understands what you said, figures out what you meant, and responds back with a voice. It also shows everything happening in a clean web interface using Gradio.

What It Can Do
Listen to your voice and convert it into text
Speak responses back to you
Answer basic questions like time, greetings, and simple queries
Tell jokes (because why not)
Fetch short summaries from Wikipedia
Detect whether your input sounds positive or negative
Generate responses using AI when it doesn’t have a fixed answer
Show everything in a live chat-style interface
Tech Stack

This project pulls together multiple tools:

Python
Gradio (for UI)
SpeechRecognition (for voice input)
gTTS (for speech output)
Hugging Face Transformers (for NLP tasks)
Wikipedia module
Pygame (for playing audio)

This project is a good foundation if you're exploring AI + voice interfaces. But the real value comes from what you build on top of it.

Right now, it shows that you understand how to combine multiple technologies. The next step is proving you can make it reliable and intelligent.
